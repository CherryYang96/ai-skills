# 知识库模板使用说明

配合 **dashboard-reporter skill V3** 使用，帮助你快速搭建自己业务的经营解读知识库。

## 模板文件

| 文件 | 用途 |
|------|------|
| `01-指标口径-template.md` | 核心指标定义、计算公式、口径差异（解读前必读） |
| `02-解读规则与归因-template.md` | 解读操作规范、归因框架、红线规则、优秀标准 |
| `03-业务规律-template.md` | 周期性规律、季节规律、竞争规律（排除正常规律后找真异动） |

## 使用步骤

### 第一步：复制模板到知识库目录

```bash
cp templates/01-指标口径-template.md 01-指标口径.md
cp templates/02-解读规则与归因-template.md 02-解读规则与归因.md
cp templates/03-业务规律-template.md 03-业务规律.md
```

### 第二步：替换所有占位符

在文件中搜索 `[示例值` 或 `[请` 开头的占位符，全部替换为你业务的真实数据。

常见占位符：
- `[目标城市]` → 你负责的城市/区域名称
- `[竞对平台]` → 主要竞争对手名称
- `[示例值，请替换为实际数据]` → 填入你业务的历史实测数据
- `[请根据历史数据校准]` → 根据你的历史数据拟合后填入

### 第三步：配置 subagent

在 `dashboard-reporter` skill 配置中，指定：
- **知识库路径**：`knowledge-base/` 目录下的 `.md` 文件路径
- **Subagent session key**：你的 LLM 解读 subagent 的 session key（如 `agent:moke:main`）

> 没有 subagent 时，skill 会自动降级到 Python 模板模式（V2 兼容）。

### 第四步：积累案例

随着每日日报运行，`knowledge-base/daily-reports/` 目录会自动积累案例，解读质量会持续提升。

## 注意事项

- 模板中保留了外卖行业的通用方法论框架（归因、M值分析、用户分层等）
- 具体业务数值（警戒水位、回归系数等）需要根据你自己城市/业务的历史数据校准
- 建议先用 1-2 个月的历史数据拟合，再正式启用 LLM 解读
