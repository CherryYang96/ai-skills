# 经营/专题分析质量评价框架

## 三维度评价标准

### 维度一：认知价值
**核心问题**：读完之后，对这个生意的理解有没有改变？

- ✅ 好的：能明确说出「和没读之前相比，对这个市场/用户/场景的认知哪里更新了」
- ❌ 坏的：读完只能说「发生了很多事情」，和没读一样
- ⚠️ 高频坑：把**场景观察**当**经营认知**——「某用户群在节假日期间早餐需求旺盛」是现象，不是认知迭代
- 评分标准：
  - A：提出了反直觉结论，或明确更新了对某个规律的判断
  - B：有洞察但没有推导到「我们对X的理解改变了」
  - C：全文都是观察和描述，没有认知层面的推进

### 维度二：归因质量
**核心问题**：结论是排除法得出的，还是凑出来的？

- ✅ 好的：控制变量、有量级、能回答「如果不是这个原因，数据会是什么样？」
- ❌ 坏的：罗列一堆可能原因，没有证明哪个是主因哪个是次因
- ⚠️ 高频坑：有方向无量级——「天气因素带动增长」但不写「贡献+X pp」
- ⚠️ 注意：相关性≠归因，问卷相关性≠行为因果；有量级但无排除法最多B+
- 评分标准：
  - A：排除法论证 + 所有因子有贡献度量级 + 有反事实验证或对照组
  - B：主要因子有量级，但部分因子只有方向
  - C：只有方向描述，无量级，多因子未分主次

### 维度三：行动指向
**核心问题**：分析结论能不能转化成决策？

- ✅ 好的：结论直接对应「要做什么」或「要盯什么」，有触发条件和操作量级
- ❌ 坏的：结论是「需要持续关注」「后续可以研究」——这是把问题推回给读者
- ⚠️ 高频坑：趋势洞察缺量级——没有量级的趋势观察是内容策划案，不是经营分析
- 评分标准：
  - A：每个结论都有明确的下一步行动、触发条件或跟踪阈值
  - B：有部分可执行建议，但关键结论停留在「关注」层面
  - C：全文结论都是「后续可以关注/研究」

> **记者 vs 分析师**：记者描述翔实但没有立场；分析师要有观点、有量级、有判断。

## 三种读者视角的追问

### 决策者视角（GMV负责人/业务VP）
关注：结论是什么 → 我该怎么做 → 资源要不要动
- 「这篇文章的核心结论用一句话怎么说？」
- 「基于这个结论，我现在应该做什么/不做什么？」
- 「如果我接受这个结论，需要动哪些资源？」

### 策略执行者视角（产品/运营）
关注：这个归因对不对 → 我的策略有没有被冤枉 → 下一步具体动作
- 「这个因子的量级足够支撑现有策略调整吗？」
- 「归因结论会不会影响到我正在做的策略判断？」
- 「下周我应该盯哪个指标来验证这个结论？」

### 数据质疑者视角（交叉团队/peer review）
关注：口径是否一致 → 因果假设是否成立 → 有没有混淆变量
- 「这个DID的平行趋势假设验证过吗？」
- 「有没有可能是X导致了Y，而不是Y导致了X？」
- 「这个WoW的基期是否受到节假日影响？」

## 常见高频问题模式（来自历史案例）

### 问题类型一：节假日WoW失真
- 现象：节后3-7天WoW数据异常（大幅负增长或正增长）
- 根因：基期踩在节假日高峰，WoW失去比较意义
- 正确做法：用「节前同期」vs「节后同期」做对比，或用日均绝对值判断

### 问题类型二：场景观察堆砌
- 现象：节假日WBR里有大量场景洞察（赏花游/节庆消费/特定人群）
- 缺失：每个场景对整体经营指标的贡献量级
- 改进：对每个场景洞察追加「这个场景贡献了多少pp的增长/下滑」

### 问题类型三：归因深度不均衡
- 现象：某周/某事件归因详细有量级，另一周/另一事件只有定性描述
- 改进：保持所有时段的归因精度一致，或显式标注「X因子待量化」

### 问题类型四：结论停留在观察层
- 现象：「高价值用户ARPU WoW -X%」后面只写「主因节后偶发性需求回落」
- 缺失：这是波动还是结构性弱化？下周如果没回归基线，说明什么，要做什么？
- 改进：每个监控指标需要有「正常范围判断」+ 「超出正常范围的触发动作」

### 问题类型五：连续同一归因未升级处理
- 现象：连续两周对同一指标归因为「偶发性需求回落」
- 改进：单次偶发可接受，连续两周应给出「预计X周回归基线，若未回归则触发XXX动作」

### 问题类型六：重要负因子归因缺失
- 现象：发现某关键因子（如某渠道流量大幅下滑）只有一句注释
- 缺失：是主动策略还是被动失控？下一步是否维持？
- 改进：凡是影响整体结论方向的单一大因子，必须明确说明「是否为计划内」

## 可复用写作模式总结

> 以下模式来自正面案例拆解，初学者可直接套用。

### 模式A：数据打破朴素假设结构
```
朴素假设（某直觉判断）
→ 数据否定（实际数字说明直觉是错的）
→ 正确假设（真实机制是X）
→ 策略推导（因此应该做Y而非Z）
```
关键：「假设被打破」才是认知迭代的触发点，而不是「发现了什么现象」

### 模式B：三段式策略提案
```
① 用户洞察（问卷数据 + 访谈引语）——why用户有这个需求
② 数据盘点（量级：多少人/日、多少占比）——how big
③ 策略启示（具体行动）——how to do
```
访谈引语不是装饰，是量化结论之外补充用户动机的质性佐证。

### 模式C：主动设置议题，而非把问题推给读者
- ❌ 错误：「后续可以关注X，待进一步研究」
- ✅ 正确：「核心判断是X，基于此有三个落地选项①②③，请确认选哪个」
- 读者任务是「选择」，不是「思考」

### 模式D：先建「防守天花板」，推导增量必须来自新方向
```
① 算清「只做防守」的上限（如：守住历史高价用户只能保住X%高价单量）
② 证明增量只能来自其他方向（如：Y%高价用户上月是中低价用户，增量必须来自跃迁）
③ 然后才提「新方向」的投入逻辑
```
不先建上限就直接说新方向，读者不知道为什么值得投入。

### 模式E：发明新指标解决旧框架解决不了的策略取舍问题
```
旧框架无法判断：「这笔补贴该不该发」
→ 定义新指标：高价单撬动比 = 次月高价单量 ÷ 当月低价单量
→ 新指标给出判断：撬动比 > 1 → 补贴值得保留
```

### 模式F：用「真实生活中的人」定义分类坐标系，而非用「平台行为数据」
```
错误做法：用「高频/低频 × 高价/低价」直接分类（数据分类但无场景感）
正确做法：先问「什么类型的生活方式决定了外卖/平台的使用模式」，再建坐标系
```
优势：策略建议有场景感和生活依据，不是抽象的「高频高客单用户」

### 模式G：竞对飞轮机制拆解 → 找到己方的战略干预点
```
① 理解竞对的商业逻辑（不是「他们在做什么」，而是「他们为什么这么做」）
② 找到飞轮的薄弱节点（路径A/路径B哪个更脆弱）
③ 找时机窗口（什么时候竞对的飞轮最容易被打断）
```

### 模式H：情景规划+量化边界
```
① 建立关键变量之间的数量关系（经验方程或相关性曲线）
② 识别关系成立的边界条件（什么情况下方程失效）
③ 给出操作区间建议（如：变量X维持在a-b范围内）
```
用于：补贴策略、定价策略、竞争响应策略等需要精确操盘的场景

### 模式I：从相关性→交叉效应→战略推论
```
Step1. 建单变量模型，发现解释力不足
Step2. 引入第二变量，解释力提升
Step3. 发现两变量可能共线，引入交叉项，解释力进一步提升
Step4. 从交叉项系数符号和业务含义推导战略
       （交叉项为负→两者协同才有破坏力→单边进攻可化解）
Step5. 给出具体反制路径（只需破坏一侧即可瓦解对手的组合攻击）
```
适用场景：有两个可能共同作用的竞争变量（流量/补贴、价格/品质、规模/频次等）

## 好分析的结构共性

### 研究类分析的三层标准结构
1. **建「分类坐标系」**：用什么维度看世界（这个维度选择本身就是认知判断）
2. **量化「每个象限的经营价值」**：值不值得投入，上限在哪，增量来自哪里
3. **给「差异化的增长和竞争策略」**：不同象限不同打法，一一对应不能混用

### 方法论等级（研究方法对可信度的影响）
- 最强：三角验证（行为数据 + 问卷量化 + 深度访谈）
- 次强：混合方法（问卷 + 访谈 + 后台数据）
- 可接受：单一方法但样本量大 + 结论有量级
- 不可接受：只有定性描述 + 无量级

### 增量机会量化的最低标准（5步框架）
```
Step1. 目标人群规模（X万人/日）
Step2. 意向场景漏斗（X万人符合触发条件）
Step3. 当前转化率 vs 潜在转化率（gap = X pp）
Step4. 假设改进幅度（基于历史干预数据）
Step5. 增量 × 均值 = GMV/订单量 / 补贴 → ROI
```
没有Step5的机会分析只是「感觉有机会」，有Step5才是「值多少钱」。

## 分析质量评级参考（匿名案例）

> 以下案例均已脱敏，只保留分析逻辑和写法，不含原始文档信息。

### WBR类（周度经营回顾）

**案例W1：B/A-/B-（正面参考）**
- 亮点：GMV WoW桥图做得标准——DAU/转化率/日频次/客单价各自有量级；特殊事件（自然灾害）做了区域分化分析（途经地 vs 登陆地效应）
- 缺陷：关键负因子（如某渠道买量流量WoW大幅下滑/-X pp）只有注释，未说明是主动收缩还是被动失控；这一判断直接影响下周策略方向

**案例W2：B/B+/B（正面参考）**
- 亮点：用户×工具（PHF/付费券包/神会员）二维分层量化，直接回答「补贴结构变化对哪类价格带用户影响几何」；商品动销SKU价格三时点监控（节前/节中/恢复期），把商家调价行为变成可追踪指标
- 缺陷：天气与竞争对转化率的双重影响合并处理，未量化各自贡献（这个拆分直接决定是否需要跟进补贴）；大部分结论无触发阈值

**案例W3：B-/B+/B-（轻微反面）**
- 问题一：食安舆情导致品类订单WoW明显下滑，发现连带效应后只说「持续监控后续走势」，缺：品类恢复周期参考、竞品是否同步受损、是否需要主动干预（资源位/补贴）、不干预的触发条件是什么
- 问题二：高价值用户ARPU/回购率连续两周同样归因「节假日偶发性需求回落」，应升级为「预计X周回归正常水位，若3w3仍未回归则说明结构性弱化，触发XXX动作」

**案例W4：C/B/B-（反面示范）**
- 问题：大量场景观察（节庆/消费趋势/人群洞察）被当作经营认知，每个观察都没有对整体经营指标的贡献量级
- 结论：「场景观察 ≠ 经营认知」，再丰富的场景描述如果没有量级归因，在WBR里就是无效内容

### MBR类（月度经营回顾）

**案例M1：B+/B+/B（发现问题阶段）**
- 亮点：发现竞争触发阈值——流量比和补贴比同时超过某临界值时，订单M值出现拐点；价格带×工具（PHF/付费券）双维分析有量级
- 缺陷：触发阈值只是历史相关性，未验证因果；PHF在本地市场失效的发现后，未给「那应该投谁/怎么调」

**案例M2：B+/B+/B+（机制深挖阶段）**
- 亮点：「悖论破解」写法——先呈现补贴比下降但M值回升缓慢的矛盾现象，再用流量比高位压制解释机制
- 亮点：收补情景推演双版本（乐观/现实），订单量和M值均有量级，把「收不收补」从定性讨论变成量化决策框架
- 缺陷：流量比压制M值的解释是相关性推断，未控制其他变量；策略讨论题均无作者答案

**案例M3：A/B+/B（规律提炼阶段）**
- 亮点：「增量市场中己方订单份额净流出」——用市场整体订单增速 vs 己方订单增速打破「我们在增长」叙事（模式A教科书）
- 亮点：持续交易用户结构命名（「哑铃型」vs「金字塔型」），比「低频增/高频减」描述更有策略含义，直接指向不同的经营重点
- 亮点：城市特有的补贴弹性非对称性——进攻效率低于全国，但收补代价高于全国，从12个月数据提炼城市经营规律
- 缺陷：补贴弹性非对称是经验性推论，机制未验证；损益bridge中高打期补贴的ROI未被评估，「不下牌桌」策略核心前提悬空

**案例M4：A/A/B+（建模+实验阶段）**
- 亮点：补贴比-订单M值经验方程 + 残差异常检测，发现「低价订单占比低于某阈值时方程失效」的边界条件（模式H）
- 亮点：流失用户三层拆分（不进站/进站不下单/进站降频），三种机制对应三种干预策略，精确分配资源
- 亮点：科学收补A/B实验——平台补贴率对齐条件下对照组 vs 实验组，ROI有量级，是MBR系列首次真正意义对照组
- 缺陷：A/B实验仅验证短期ROI，未跟踪中长期留存；履约降本三个方向无量级

**案例M5：A+/A+/A-（建模升级阶段）**
- 亮点：流量比+补贴比双变量+交叉项回归，R²从单变量0.61→双变量0.81→含交叉项0.91，每步验证解释力提升；p<0.001
- 亮点：交叉项负系数的业务推论——「流量比和补贴比同时高位才危险，单边进攻可用单边反制化解」，直接给出两条反制路径（模式I）
- 亮点：节假日期间DAU结构拆分（旅游/留守/本地），各来源人群有交易频次、客单价、品类偏好量级，直接支撑精细化运营
- 缺陷：某品类心智流失（订单WoW大幅下滑）预警发现及时，但品类营销反制量级未给

### 研究/专题分析类

**案例R1：A/B+/B+（打破朴素假设型）**
- 亮点：用数据打破「补贴→召回竞对用户」的朴素假设，真实数据显示核心流失原因是心理机制（损失厌恶），而非价格差距（模式A）
- 亮点：三段式策略提案（竞对用户独占现状洞察→独占时长与回流率量化→「想得起/舍得下/粘得住」三阶段策略）结构完整（模式B）
- 缺陷：损失厌恶占比数据来自问卷相关性，非行为数据因果验证；各策略阶段的补贴/资源量级未给

**案例R2：A/B+/B+（用户行为机制研究型）**
- 亮点：混合研究方法——大盘数据+问卷+视频饮食日记，其中视频日记法捕捉用户决策中途的实时心理变化，是问卷无法覆盖的
- 亮点：量化了用户session时长与年留存率的分组差异，发现关键时间拐点（某分钟之后长session反而损害留存），把行为现象转化为可监控的经营风险
- 缺陷：时间拐点是分组对比，未控制「长session用户本身可能是决策困难人群」的选择偏差；三个策略方向均无订单/留存影响量级

**案例R3：A+/A/A（防守天花板+价格带跃迁策略型）**
- 亮点：先量化「只守住历史高价用户」的GMV上限，证明增量必须来自中低价用户向高价跃迁（模式D）——不先建天花板直接说新方向，读者不知道为什么值得做
- 亮点：发明高价单撬动比（次月高价单量 ÷ 当月投入低价单量）解决「这笔补贴该不该发」的策略取舍（模式E）；用户跃迁潜力按行为层/偏好层/能力层/身份层四级分层，各层有跃迁率量级
- 亮点：A/B实验有完整ROI量化，30天内高价单增量清晰
- 缺陷：撬动比仅验证30天效果，时间衰减未验证；各城市撬动比差异大，无通用操盘标准

**案例R4：A+/A/A（人群分类坐标系+竞对飞轮拆解型）**
- 亮点：用「时空自由度×消费力」建立用户分类坐标系——打破「高收入=高外卖频次」假设，改用真实生活方式决定使用模式（模式F）
- 亮点：竞对飞轮两条路径（路径A：外卖核心人群→带动电商 vs 路径B：会员电商人群→渗透外卖）分别用数据验证，找到路径B是主战场和战略干预时机窗口（模式G）
- 亮点：增量机会5步量化链路——目标人群规模→意向场景漏斗→转化率gap→补贴做功范围→日增GMV/ROI，链路完整
- 缺陷：连单GMV增量ROI估算区间宽达5倍，实际落地精度有限；对低价用户「技巧性收补」策略的伦理边界未讨论
